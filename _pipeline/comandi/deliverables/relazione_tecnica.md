# Deliverable — Relazione tecnica

Agente: `offer-writer`. Procedimento: skill `deliverable-relazione-tecnica`.

## Esecuzione

Un documento unico per tutti i criteri inclusi nella Sezione B di
`vincoli_offerta_tecnica.md`, prodotto per stadi: scaletta → bozza →
definitivo. Il prompt dice quale stadio eseguire e quale file scrivere
nella cartella del deliverable (`output/10_offer/<id>/`): esegui solo
quello, secondo la skill, e fermati. Gli stadi già approvati vanno
seguiti fedelmente.

## Prerequisiti

Fase 6 confermata: proposte approvate nei nodi di `02_graph/proposals/`,
Sezione B di `vincoli_offerta_tecnica.md` compilata. Se manca un
prerequisito, non scrivere output parziale: spiega cosa manca.
