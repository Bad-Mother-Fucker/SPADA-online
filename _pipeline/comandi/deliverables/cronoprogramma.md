# Deliverable — Cronoprogramma migliorativo

Agente: `deliverable-cronoprogramma`.

## Esecuzione

Segui `deliverable-cronoprogramma` come descritto nel proprio file
agente: legge il cronoprogramma di progetto se presente, le proposte
approvate, produce l'impatto temporale delle migliorie in formato
tabellare (ed eventualmente Gantt testuale) in
`output/10_offer/{deliverable_id}/cronoprogramma_migliorie.md`.

## Prerequisiti

Almeno una proposta approvata.
