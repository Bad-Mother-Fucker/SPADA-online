# Deliverable — Tavole tecniche (elenco e note)

Agente: `deliverable-tavole-tecniche`.

## Esecuzione

Segui `deliverable-tavole-tecniche` come descritto nel proprio file
agente: identifica quali tavole di progetto vanno aggiornate o quali
nuove tavole servono per rappresentare le proposte approvate, con le
note tecniche per chi le disegnera'. Non produce disegni CAD.

Output: `output/10_offer/{deliverable_id}/elenco_tavole_migliorie.md`

## Prerequisiti

Almeno una proposta approvata.
