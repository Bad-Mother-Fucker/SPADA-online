# Checklist — Estrazione criteri dal disciplinare

## Prima dell'estrazione

- [ ] Ho individuato la sezione criteri valutativi dell'offerta tecnica
- [ ] Ho verificato se esistono allegati separati con i criteri
- [ ] Ho verificato se ci sono note o errata corrige al disciplinare

## Durante l'estrazione

- [ ] Ho estratto tutti i criteri (nessuno saltato)
- [ ] Ho assegnato ID stabili C1, C2, C3... in ordine
- [ ] Per ogni criterio ho il punteggio massimo
- [ ] Per ogni criterio ho i subcriteri con punteggi parziali
- [ ] Per ogni criterio ho il metodo di attribuzione punteggio
- [ ] Ho identificato elementi premianti espliciti
- [ ] Ho identificato vincoli espliciti
- [ ] Ho identificato vincoli impliciti (requisiti tecnici minimi)
- [ ] Ho segnalato limiti dimensionali o formali
- [ ] Ho segnalato rischi fuori scope

## Dopo l'estrazione

- [ ] Ho creato `criteria_matrix.md` con tabella completa
- [ ] Ho creato `criteria_matrix.json`
- [ ] Ho creato `criteria_checklist.md`
- [ ] Ho creato un file `criterion_Cx.md` per ogni criterio
- [ ] Ho verificato che il totale dei punteggi sia corretto
- [ ] Ho verificato che nessun vincolo importante sia stato perso
